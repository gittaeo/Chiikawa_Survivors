# 에셋 출처와 이용 범위

이 프로젝트는 치이카와를 소재로 만든 **비공식 로컬 팬게임 시제품**입니다. 공식 게임 또는 공식 라이선스 제품이 아닙니다.

## 캐릭터 스프라이트

- 출처: [heelee912/chiikawa-dots-pets](https://github.com/heelee912/chiikawa-dots-pets)
- 고정 리비전: `bb96582f525fbdf88a236b4703433ae92bfd5888`
- 사용 파일: `pets/{character}/spritesheet.png`, 11명
- 규격: 1536 × 2288 PNG, 8열 × 11행, 셀 192 × 208
- 게임은 쉬기, 좌우 달리기, 인사, 실패 모션을 사용합니다. 공격 무기와 효과는 게임 코드에서 별도로 그립니다.

원본 저장소는 비공식 팬 제작물이며, README에 **상업적 이용과 재배포를 허락하지 않는다**고 명시합니다. 캐릭터와 이름의 권리는 나가노 및 각 권리자에게 있습니다. 코드 공개나 다른 저장소의 라이선스가 이 권리를 대신 부여하지 않습니다.

따라서 원본 스프라이트는 이 Git 저장소에 포함하지 않았습니다. README의 캐릭터 미리보기는 원본 저장소의 GIF를 직접 참조합니다. 실행하려는 사용자는 원본 안내와 조건을 확인하고 로컬에 직접 준비해야 합니다. `scripts/fetch-assets.mjs`는 해당 원본 리비전에서 로컬 파일을 받는 편의 도구이며, 별도 이용 허락을 부여하는 도구가 아닙니다.

다운로드한 `assets/chiikawa/`는 `.gitignore`로 제외합니다. 공개 웹 호스팅, 배포 파일, 컨테이너 이미지, 릴리스 ZIP 등에 원본 이미지를 다시 넣지 마세요. Google Play 등 공개 배포와 광고·결제 수익화에는 필요한 별도 권리 확인·허락 또는 권리가 정리된 독자 에셋으로의 교체가 필요합니다.

## 화면과 게임용 창작

`docs/screenshots/`에는 기능을 소개하는 실제 로컬 플레이 화면을 수록했습니다. 화면에 보이는 캐릭터의 권리는 그대로 원권리자에게 있으며, 스크린샷 공개가 캐릭터 에셋 사용 허락을 뜻하지 않습니다. 스크린샷을 캐릭터 스프라이트의 대체 배포물로 제공하는 것도 아닙니다.

무기 궤적, 맵 배치, UI, 효과음 합성, 능력 수치, 고유기·진화 조합은 팬게임을 위해 작성한 표현입니다. 고유기 이름과 스킬 목록은 원작의 공식 기술 목록이 아닙니다. 애니메이션 OST·음성·영상 캡처나 상용 게임에서 추출한 파일은 포함하지 않았습니다.

참고한 공개 자료:

- [치이카와 애니메이션 공식 사이트](https://www.anime-chiikawa.jp/)
- [공식 사스마타 상품 자료](https://chiikawamarket.jp/products/4970381627768)

별도의 상업적 이용 허락이나 법률 검토를 완료한 저장소가 아닙니다.

## 생성 배경

`assets/environments/golden-forest.png`와 `moon-cavern.png`는 built-in ImageGen으로 새로 생성한 배경입니다. 숲의 따뜻한 햇살과 섬 동굴의 청록빛을 모티브로 하며, 원작 영상에서 추출한 프레임이 아닙니다. 프롬프트 방향은 README의 Visual update에 기록했습니다.

### 공유 페이지의 캐릭터 로딩

로컬 PNG가 없으면 원본 팬 아트 저장소의 고정 리비전 이미지를 직접 참조합니다. 원본 PNG를 이 저장소에 복사하거나 공개 호스팅하지 않습니다. 외부 원본의 가용성에 따라 캐릭터 로딩이 실패할 수 있으며, 직접 참조가 공개 사용·상업적 이용 허락을 의미하지는 않습니다.
